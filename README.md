# Hatsune Miku - DigitalArt Code Animation #1

## English

In this mini-project, my proposal was to recreate an illustration of the iconic Hatsune Miku using a unique typographic approach, where the word "miku" itself is continuously repeated to bring the character's shapes, shadows, and colors to life. To achieve this result, I used HTML5 & CSS3 for the structuring and to define the page's crisp visual styling; to highlight the artwork as much as possible, I opted for a deep black, borderless background, ensuring a clean and modern aesthetic. JavaScript was responsible for manipulating the logic of the typographic grid and creating the magic of movement. Finally, for Animation & Motion, I applied a continuous displacement effect where the letters slide smoothly to the left, bringing a fluid and expressive dynamism to the image directly in the browser.
