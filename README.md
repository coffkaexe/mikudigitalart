In this mini-project, I used the Canvas API and JavaScript to create Miku! Basically, I calculated the screen and letter sizes to build a grid with columns and rows, then I took the original Hatsune Miku image, processed its pixelData (the data of each pixel's color and transparency), and used this information as a mask to determine exactly where to draw and which color to apply to the words "miku", and finally, I added a CSS animation to make the text continuously slide to the left!
